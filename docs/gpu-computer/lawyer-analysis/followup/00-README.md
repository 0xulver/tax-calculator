# Follow-up research prompts — GPUcomputer / Szklarski case

These prompts were written after adwokat Piotr Proniewski's analysis
(`../analysis.md`). They are designed to be run by me, independently, in a
deep-research tool (ChatGPT / Perplexity / Gemini). The goal is to decide
strategy **without paying the lawyer further**, and to surface only the
genuinely hard questions for a possible final lawyer consultation.

Each prompt is self-contained (it repeats the case facts) so it can be pasted
in on its own. They deliberately go **deeper and more case-specific** than the
existing research in `../../crime-law/` and `../../` — they do not re-ask the
basics already answered there (art. 286 KK elements, JDG personal liability,
KRZ mechanics, EPU sprzeciw rules).

| # | File | Question |
|---|------|----------|
| 1 | `01-how-to-file-zawiadomienie.md` | How do I file the fraud complaint myself, from abroad, without a lawyer? |
| 2 | `02-realistic-outcomes-and-recovery.md` | What is the realistic outcome — and does it ever return my money? |
| 3 | `03-pinning-waldek-coperpetrator.md` | How could Waldek be held responsible (criminally, then civilly)? |
| 4 | `04-epu-and-criminal-parallel.md` | Can the EPU and the criminal case run at once — can both succeed? |
| 5 | `05-epu-enforcement-empty-account.md` | If the EPU title is won but the company account is empty, then what? |
| 6 | `06-cross-border-enforcement-netherlands.md` | Can I collect from him in the Netherlands? Steps and cost. |
| 7 | `07-bankruptcy-shield-491-pu.md` | How does a fraud conviction make the 155k non-dischargeable forever? |
| 8 | `08-criminal-procedure-role-and-cost.md` | Does the prosecutor run the case for free, or must I pay a lawyer? |
| 9 | `09-non-criminal-pressure-levers.md` | Business-ban (art. 373 PU) and KAS/VAT levers tied to the clean KRZ. |
| 10 | `10-misrepresentation-fake-front-fraud.md` | Fraud by pre-payment misrepresentation: the "fake front" theory, on evidence I already hold. |
| 11 | `11-finding-other-victims.md` | OSINT hunt for other GPUcomputer victims — pattern proof + crossing the 200k art. 294 threshold. |

Results live in the numbered subfolders (`1/`–`10/`), one file per model run.
Each subfolder has a **`00-summary.md`** distilling all model outputs for that
question: bottom line, consensus findings, model disagreements, action
checklist, and caveats. Read the summaries first; open the full outputs only
when a specific point matters.

After running these, collect remaining uncertainties into a short list of
questions worth a single paid lawyer session.
